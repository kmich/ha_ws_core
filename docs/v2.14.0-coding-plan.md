# Weather Station Core v2.14.0 coding plan

**Status: proposed - implementation has not started.**

Prepared 17 November 2026. This is the file-level companion to the [v2.14 and v3.0.0 release plan](v3.0.0-release-plan.md) (scope A1, milestones M0 and M1). It authorizes no code changes, release or publication. Every line number below refers to 2.13.17 (commit `915cf667594207bacb0edd5e1ba009b028dce0bf`) and must be re-checked after M0 refreshes main.

## How to read this plan

- Each work item lists the **place** in the code, the **change**, the **failing test to write first** and the **changelog line**. A fix is accepted only when its test fails on 2.13.17 and passes after the change.
- Items that I have not yet confirmed in the source say so under "Open check". Do not code those until the check is done.
- v2.14.0 has no learned-state change and no storage schema version bump. The one exception is a single new optional field in the learning state (see item 21); it has a default, so old stored data loads unchanged and the schema version stays the same.

## Delivery structure

| Step | What | Notes |
|---|---|---|
| M0 | Baseline and decisions (below) | Nothing merges before the minimum-version decision is recorded |
| Integration branch | `feat/v2.14.0`, cut from refreshed `main` | Matches the project's habit of one PR per release; here the PRs target the integration branch |
| PR 1 to PR 6 | Work groups, in the order below | Each PR: failing tests first, then fixes, green CI, own changelog fragment |
| PR 7 | Release PR: `manifest.json` to `2.14.0`, `CHANGELOG.md`, docs | Bump `manifest.json` before tagging or CI fails. Commits and PR bodies carry no "Generated with Claude Code" footer |

Order is low risk first, and each group is independent of the later ones, so a stalled group does not block the others.

## Risks and how this plan handles them

- **Output changes in a "fix" release** (climatology values, nowcast rows, Pirate Weather precipitation, soil): each has a changelog line and a test that pins the new value.
- **Scope creep:** v2.14.0 has 28 items. Each is small, independent and in its own commit; if time runs short, groups from the end (PR 6, then PR 5) can move to the next release without affecting the rest.
- **Unverified items:** items 8, 10, 13, 16, 27 and 28 carry an "Open check". They are investigated first and dropped or reshaped if the check disproves the premise.
- **No learned-model change:** Pattern Forecast, standardizer and weights are not touched in v2.14.0; that migration is v3.0.0 work.
