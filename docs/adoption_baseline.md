not an installation counter and does not use integration telemetry.

## Monthly review

Record repository visitors and top referrers, stars, forks, release downloads,
documentation visits, setup issues by category, median first response, compatibility
reports, first-time contributors, returning contributors, and the result of the month's
main adoption experiment. Leave unavailable metrics marked **not collected** rather than
recording zero.
